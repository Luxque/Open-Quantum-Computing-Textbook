# Security

## Document Description

This document suggests potential security vulnerabilities of this project and provide contact information for reporting such issues.
Thank you for your vigilance and watchfulness.

## Potential Vulnerability

The biggest concern would be arbitrary code execution via the distributed PDF edition.
Before every push to main, the PDF will be freshly recompiled from scratch after a code screening.

## Contact

You can file a report regarding potential vulnerabilities and security issues to the [Security Advisories](https://github.com/Luxque/Open-Quantum-Computing-Textbook/security/advisories) tab of this repository.
