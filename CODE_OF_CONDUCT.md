# Code of Conduct

## Document Description

This document defines the morale code of the project *Open Quantum Computing Textbook* that every project maintainer and contributor must follow.

## Mission

This project aims to build an open and inclusive learning environment for anyone who is interested in quantum computing, from its theory to application.
In the interest of fostering such an environment, we as contributors and maintainers are expected to follow the rules listed below.

## Code

1. **The main language of communication is English.**
This rule is solely for establishing a main communication standard in this project.
You are always more than welcome to contribute by translating the original texts to different languages in this project.
2. **Any kind of hate speech is strictly prohibited.**
Hate speeches include, but not limited to: age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, and sexual identity/orientation.
3. **Any criticisms and feedback must be constructive.**
Criticisms must not include condemnation by any means and should be gracefully accepted.
4. **Respect everyone's private information.**
Never share your or someone's physical/electronic addresses, real name, password, etc. in public.
If you have to mention any of them, please obtain a proper permission from them.
5. **Do not advocate for malicious activities.**
Any commits and comments encouraging such behaviors will be deleted on-site and reported to GitHub and law enforcement depending on the severity.
6. **Avoid using generative AI.**
One of the most important objective of this project is to build a handful collection of verified human knowledge in quantum computing and related fields.
Misuse of generative AI may pulverize such intention by overrunning the management taskforce, spreading misinformation, and depriving the quality of work.
Please consult the [Generative AI Policy](./CONTRIBUTING.md#generative-ai-policy) section in the [Contributing](./CONTRIBUTING.md) document before committing any contribution.

## Responsibility

Project maintainers have the right and responsibility to remove comments and reject commits that are not aligned to this code of conduct, or to ban temporarily/permanently any contributor for other behaviors that they deem inappropriate or harmful.

## Scope

This code of conduct applies to the entire repository of this project, including [Issues](https://github.com/Luxque/Open-Quantum-Computing-Textbook/issues), [Pull Requests](https://github.com/Luxque/Open-Quantum-Computing-Textbook/pulls), and [Discussions](https://github.com/Luxque/Open-Quantum-Computing-Textbook/discussions) tabs.
